Agentic Observability Platform

Agents phone home from anywhere → the OTel Collector fans out: spans to LangFuse v3 (trace / eval / cost), spanmetrics to Prometheus → Grafana (agent ↔ infra ops). Local-first, Azure-ready.

Telemetry flow (phone-home)

  • • Agents emit OpenTelemetry via the sdk/ facade — never langfuse directly
  • • Ingress terminates TLS, enforces per-client token / mTLS
  • • Collector is the single wire-level swap point + PII redaction
  • • One credential per client engagement — revocable, attributable

Two planes, not redundant

  • • LangFuse: trace / eval / cost / token deep-dives — the LLM analytics home
  • • Grafana + Prometheus: agent RED over host/container/DB metrics
  • • Answers "model or box?" in one pane; Alertmanager paging
  • • spanmetrics exists because LangFuse exports no Prometheus metrics

Storage & portability

  • • ClickHouse = traces (OLAP, the big grower) · Postgres = metadata
  • • Redis = async queue/cache · MinIO/Blob = event uploads
  • • Two swap points: sdk/ facade + Collector exporter config
  • • Real lock-in stays in eval/scoring — portable elsewhere
