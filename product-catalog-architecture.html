Product Catalog Platform — AWS EKS Architecture (Draft v1)

Angular + FastAPI + PostgreSQL CRUD app, deployed to Amazon EKS via CloudFormation, CI/CD via GitHub Actions, observability via kube-prometheus-stack. This is a draft for review before we build.

CI/CD Pipeline (GitHub Actions)

  • • CI: lint, unit test, build Angular + FastAPI Docker images
  • • CI: push versioned images to Amazon ECR
  • • CD: deploy/update CloudFormation stacks (VPC, EKS, RDS, IAM)
  • • CD: helm upgrade kube-prometheus-stack + kubectl apply app manifests
  • • Auth: GitHub OIDC → federated IAM role, no static AWS keys in CI

Kubernetes Objects — namespace: app

  • • Deployment × 2 (frontend, backend) — desired state for pods/ReplicaSets
  • • Service × 2 (ClusterIP) — stable virtual IP + DNS for each Deployment
  • • Ingress + AWS LB Controller — provisions/configures the ALB, path routing
  • • HPA — scales backend pods on CPU utilization (needs metrics-server)
  • • ConfigMap / Secret — non-sensitive config vs. DB credentials
  • • ServiceAccount (IRSA) — scoped AWS permissions per pod, no node-wide creds
  • • NetworkPolicy — restricts which pods can reach the backend

Data & Observability

  • • Amazon RDS PostgreSQL, Multi-AZ, automated backups, private subnet only
  • • Prometheus (StatefulSet + PVC) — scrapes backend /metrics via ServiceMonitor
  • • Metrics: request rate, error rate, p50/p95/p99 latency, in-flight requests
  • • Grafana (Deployment) — RED dashboards, Prometheus as datasource
  • • Alertmanager — routes alerts (latency/error-rate burn) to Slack/email
